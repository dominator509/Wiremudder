## Inherited-Source Rule

No inherited path may be edited until exact source evidence exists and `.agent/expected-files/EP-005.discovered.txt` contains the required evidence header and exact path. A broad `src/` authorization is invalid.

## Acceptance Obligations

1. WireCore lifecycle is bounded and observable.
2. Local transport and encoding are selected by benchmark and ADR.
3. Qt main thread never waits on optional work.
4. Frame size, schema, deadline, cancellation, and peer identity are validated.
5. Queue overflow degrades P2-P4 work without P0 backpressure.
6. WireCore crash, hang, restart, and absence preserve manual gameplay.

## Required Failure Proofs

- Unavailable dependency or worker.
- Timeout and cancellation.
- Malformed or oversized input where applicable.
- Duplicate or replayed request where applicable.
- Denied permission, consent, route, or policy where applicable.
- Resource or queue budget exhaustion.
- Partial side effect and compensation where applicable.
- Preserved manual gameplay and data integrity.

## Security and Privacy

WIREMUDDER_SECURITY.md, SPEC-010, and SPEC-022 apply. Logs and evidence are redacted. No new authority, secret access, remote egress, package permission, routing control, signing capability, or stable publication is implied by this node.

## Performance

SPEC-004 applies. The node verifier records relevant queue, latency, cancellation, drop/coalesce, memory, CPU, and fallback evidence. P0 and P1 regressions block completion.

## Observability and Operations

The node supplies health, readiness, structured errors, metrics, diagnostics, disable, restart, backup or migration behavior where applicable, and a bounded recovery runbook.

## Live-Fire Proof

`LF-005` `sidecar-crash-isolation` at `tests/live-fire/LF-005-sidecar-crash-isolation.sh`.

## Fallback

Run WireCore only on explicit user request and keep all AI, memory, voice, and renderer features disabled while the inherited client remains fully functional.
