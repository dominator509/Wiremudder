## Inherited-Source Rule

No inherited path may be edited until exact source evidence exists and `.agent/expected-files/EP-006.discovered.txt` contains the required evidence header and exact path. A broad `src/` authorization is invalid.

## Acceptance Obligations

1. Local Only blocks all declared remote egress and downloads.
2. Secrets use OS-backed or evidence-backed encrypted storage.
3. Privacy Firewall accurately previews provider context and redactions.
4. Consent is scoped, revocable, and audited.
5. Private messages and credentials are excluded by default.
6. No optional subsystem can bypass egress policy.
