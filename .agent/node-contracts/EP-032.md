## Inherited-Source Rule

No inherited path may be edited until exact source evidence exists and `.agent/expected-files/EP-032.discovered.txt` contains the required evidence header and exact path. A broad `src/` authorization is invalid.

## Acceptance Obligations

1. All required benchmark fixtures run reproducibly.
2. P0/P1 targets pass or have evidence-backed stricter/realistic thresholds approved by ADR.
3. Queue overflow behavior matches contracts.
4. One session cannot starve another.
5. Voice/renderer/AI/storage/update degradation preserves gameplay.
6. Raw benchmark artifacts and regression limits are stored.

## Required Failure Proofs

- Unavailable dependency or worker.
- Timeout and cancellation.
- Malformed or oversized input where applicable.
- Duplicate or replayed request where applicable.
- Denied permission, consent, route, or policy where applicable.
- Resource or queue budget exhaustion.
- Partial side effect and compensation where applicable.
- Preserved manual gameplay and data integrity.

## Security and Privacy
