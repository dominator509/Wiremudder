# Node Contract EP-030: Imports, Migrations, and Client Ecosystem

## Status

Accepted blueprint node contract. Runtime implementation is not yet claimed.

## Risk

critical

## Purpose

Implement safe migration from Mudlet assets and evidence-backed import paths for MUSHclient, TinTin++, zMUD/CMUD concepts, and generic formats with disabled automation and rollback.

## Inherited-Source Rule

No inherited path may be edited until exact source evidence exists and `.agent/expected-files/EP-030.discovered.txt` contains the required evidence header and exact path. A broad `src/` authorization is invalid.

## Acceptance Obligations

1. Mudlet formats are discovered from source and corpus.
2. Every import is hashed and backed up.
3. Automation and permissions start disabled.
4. Conflicts and unsupported fields are reported.
5. Malformed and adversarial inputs fail safely.
6. Rollback leaves source and destination intact.

## Required Failure Proofs

- Unavailable dependency or worker.
- Timeout and cancellation.
- Malformed or oversized input where applicable.
- Duplicate or replayed request where applicable.
- Denied permission, consent, route, or policy where applicable.
- Resource or queue budget exhaustion.
- Partial side effect and compensation where applicable.
- Preserved manual gameplay and data integrity.

## Security and Privacy

WIREMUDDER_SECURITY.md, SPEC-010, and SPEC-022 apply. Logs and evidence are redacted. No new authority, secret access, remote egress, package permission, routing control, signing capability, or stable publication is implied by this node.

## Performance

SPEC-004 applies. The node verifier records relevant queue, latency, cancellation, drop/coalesce, memory, CPU, and fallback evidence. P0 and P1 regressions block completion.

## Observability and Operations

The node supplies health, readiness, structured errors, metrics, diagnostics, disable, restart, backup or migration behavior where applicable, and a bounded recovery runbook.

## Live-Fire Proof

`LF-030` `import-migration-disabled-automation` at `tests/live-fire/LF-030-import-migration-disabled-automation.sh`.

## Fallback

Support read-only analysis and migration reports for unproven formats; allow only verified Mudlet imports.
