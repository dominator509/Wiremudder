## Inherited-Source Rule

No inherited path may be edited until exact source evidence exists and `.agent/expected-files/EP-000.discovered.txt` contains the required evidence header and exact path. A broad `src/` authorization is invalid.

## Acceptance Obligations

1. Pinned repository and commit are reachable and checked out.
2. License and submodule inventory is evidence-backed.
3. Official build skill and available CMake presets are captured.
4. Current baseline tests and known failures are recorded without product edits.
5. Every inherited subsystem claim names a verified path or symbol.
6. No command or dependency is invented from the old blueprint.

## Required Failure Proofs

- Unavailable dependency or worker.
- Timeout and cancellation.
- Malformed or oversized input where applicable.
- Duplicate or replayed request where applicable.
- Denied permission, consent, route, or policy where applicable.
- Resource or queue budget exhaustion.
- Partial side effect and compensation where applicable.
- Preserved manual gameplay and data integrity.
