## Acceptance Obligations

1. Profile defaults persist and export correctly.
2. AI and automation cannot change sensitive defaults.
3. Supported routing profiles validate at connect time.
4. Selected-route failure never silently becomes direct.
5. Egress verification is user-triggered.
6. No abuse-oriented routing behavior exists.
