# Incident Response Checklist

- [ ] Protect manual gameplay and user data first.
- [ ] Trigger emergency stop for unsafe automation.
- [ ] Enable Local Only Lockdown for possible egress or privacy incidents.
- [ ] Preserve redacted evidence and classify severity.
- [ ] Contain, diagnose, mitigate reversibly, verify, communicate, and document.
- [ ] Add regression proof and review missed gates.
