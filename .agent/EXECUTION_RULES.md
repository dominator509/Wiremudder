# Execution Rules

1. Run the full boot sequence.
2. Preserve the Mudlet-derived foundation; no greenfield rewrite.
3. Work one leased node.
4. Implement from the active ExecPlan, never ROADMAP.md.
5. Re-ground before each milestone.
6. Verify inherited names and commands from source evidence.
7. Change only static and approved discovered paths.
8. Use COMMANDS.md wrappers.
9. Follow the bounded ladder and never repeat a fix.
10. Do not weaken, skip, ignore, or mask a gate.
11. Production paths contain no mocks, stubs, demo success, sample success, or placeholders.
12. Optional providers remain disabled until live-fire certification.
13. Commit every green milestone and append ledger evidence.
14. A node is done only with milestone evidence, node verify, expected-file and scope audit, NODE_DONE, and green tag.
15. Final reports distinguish observed facts, disabled capabilities, remaining certifications, and release status.
