# WireMudder Error Catalog

Stable error codes are created under SPEC-025 and schemas. Prefix families are:

- WM-VALIDATION
- WM-AUTHENTICATION
- WM-AUTHORIZATION
- WM-CONSENT
- WM-POLICY
- WM-UNAVAILABLE
- WM-TIMEOUT
- WM-CANCELED
- WM-CONFLICT
- WM-RATE-LIMIT
- WM-EXTERNAL-PROVIDER
- WM-STORAGE
- WM-PROTOCOL
- WM-COMPATIBILITY
- WM-SECURITY
- WM-VERIFICATION
- WM-ROLLBACK
- WM-INVARIANT

A code is added only with user-safe message, retry class, correlation, diagnostic data policy, cleanup, tests, and documentation.
