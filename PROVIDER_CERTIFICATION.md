# Provider Certification

Every model, speech, telemetry, asset, storage, package, and update provider has one record containing adapter version, provider version or API date, credential scope, locality, privacy mode, data classes, cost, limits, health, failure behavior, cancellation, rate limits, test corpus, live-fire date, evidence hash, release profiles, and state.

Compilation or a successful health call is not certification. A provider remains disabled until contract, privacy, failure, quality, performance, cost, and live-fire gates pass.
