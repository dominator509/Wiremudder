The complete first-generation ZIP file tree, recovered architecture, feature catalog, performance constitution, bug pipeline, update architecture, voice and renderer differentiators, legacy power-client compatibility update, contextual help update, and the original Graphlock master prompt were inventoried. `SOURCE_DOCUMENT_COVERAGE.tsv` has one row for every source file and recovered document. `LEGACY_REQUIREMENT_INVENTORY.tsv` captures headings, bullets, and numbered requirements with an accepted destination.

## Requirements Retained

All classic, protocol, mapper, scripting, package, import, profile, routing, command-safety, AI, memory, agent, quest, tactical, voice, renderer, soundscape, headless, help, privacy, diagnostics, update, performance, accessibility, and bug-automation features are represented in the 244-row feature authority.

## Architecture Replaced

The greenfield Tauri, React, and all-Rust desktop assumption is rejected because it recreates mature Mudlet functionality and increases compatibility risk. It is replaced by a pinned Mudlet fork, minimal Qt/C++ bridge, isolated Rust WireCore, independent oracle, and reversible strangler migrations.

## Governance Replaced

The old partial six-layer files lacked the complete graph table, deterministic scheduler, leases, append-only ledger, green-tag law, machine feature and requirement trace, source evidence, expected-file amendments, reality gate, live-fire catalog, source coverage, and full bounded node graph. Those are supplied here.

## Honesty Boundary

The pack does not claim that runtime features exist. It creates exact ownership, acceptance, verification, fallback, and release rules so later executors cannot turn planned features into fabricated completion.
