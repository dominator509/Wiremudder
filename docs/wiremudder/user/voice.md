# Voice

The voice system is an optional, degradable immersion feature (SPEC-000-R05).

## Voice Companion

The voice companion lets you use voice commands while playing. It runs
locally or through a provider you configure (WM-FEAT-0174).

## Voice Macros

Voice macros bind spoken phrases to commands. They are local, bounded, and
respect the same command-safety gates as typed input (WM-FEAT-0175).

## Microphone Permission

The microphone is a protected permission (WM-SPEC-008-R04). Nothing
accesses the microphone unless you approve it — and a package or script
cannot access it without that explicit approval.

## Privacy

Voice transcripts are local by default. Remote transcription requires
explicit configuration and consent (WM-FEAT-0177). The remote policy is
stored locally and can be reviewed.
